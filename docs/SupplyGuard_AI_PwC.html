The solution

One root Deep Agent, six specialist subagents, deterministic calculators and payload-bound human approval.

PwC
About 55 seconds. Walk through the exact five-stage pipeline implemented in src/agent/deep_agent.py and src/agent/subagents.py. 1. Triage extracts DisruptionFact; if ambiguous (e.g. just "Atlas" -> Atlas Components S001 vs Atlas Logistik S006), it pauses and asks rather than guessing. 2. Impact, Contract and Graph subagents query live Postgres ERP tables, RBAC-scoped hybrid retrieval, Neo4j Tier-2 links and the external risk service. 3. Optimizer prices 5 recovery options strictly via Python calculators (zero LLM math). 4. Challenger validates policy caps and neutralizes prompt injections; Chainlit renders an immutable SHA-256 Approval Card with Approve, Reject and Modify Plan. 5. Approved orders execute exactly once via the Simulated Procurement MCP backed by PostgreSQL audit_log locking, returning a receipt and downloadable report.

Payload binding: ApprovalPayload.compute_payload_hash() hashes supplier, qty, price, fees and cap. Any modification via Modify Plan invalidates the prior hash and increments revision. Guardrails in code

Enforced by code & Postgres, not prompts

SHA-256 payload binding & atomic idempotency

compute_payload_hash() binds supplier, quantity, unit price, fees and cap (≤ €75k); any edit invalidates approval. execute_idempotent() locks audit_log with SELECT ... FOR UPDATE and generates collision-free PO-SUP-2026-<hash> IDs.

Authenticated RBAC, provenance & source precedence

Salted scrypt login (src/db/auth.py) filters chat history and retrieval scopes before ranking; DOC-FIN-01-v1 never reaches procurement or read-only roles. Contract > qualification > notice > e-mail > chat; superseded versions are demoted.

Prompt-injection defense & crash-safe resume

scan_prompt_injections neutralizes DOC-NOT-HELIOS-PRICE and sanitize_evidence_text strips HTML comments. Container restarts (~3.0s) and SUPPLYGUARD_CRASH_AT kill points resume from Postgres with zero duplicate POs.
