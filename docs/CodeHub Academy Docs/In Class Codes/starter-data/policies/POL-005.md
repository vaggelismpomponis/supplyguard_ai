# Email Access and Mailbox Issues

Mailboxes are hosted on the Email & Calendar Service and sign in through Nimbus ID.

Sign-in failures: check outages on the Identity Provider and Email Service before any account action. Mailbox quota is 50 GB; archive requests are handled by a normal ticket.

## Rules

1. **POL-005-R01** Mailboxes are hosted on the Email & Calendar Service.
2. **POL-005-R02** Sign-in to email uses Nimbus ID (Identity Provider) with MFA.
3. **POL-005-R03** Before any account action, check open outages on the Email Service.
4. **POL-005-R04** Also check open outages on the Identity Provider because email depends on it.
5. **POL-005-R05** If an open outage explains the symptom, link the request to the outage.
6. **POL-005-R06** Do not reset the password when an explaining outage is open.
7. **POL-005-R07** Mailbox quota is 50 GB per employee.
8. **POL-005-R08** Employees are warned at 90% of quota.
9. **POL-005-R09** Archive requests are handled by a normal ticket.
10. **POL-005-R10** Archive mailboxes are retained for 7 years.
11. **POL-005-R11** The maximum message size is 25 MB.
12. **POL-005-R12** Calendar delegation is configured by the employee, not by IT.
13. **POL-005-R13** Out-of-office replies are set by the employee in Webmail.
14. **POL-005-R14** Mail forwarding to external addresses is blocked by default.
15. **POL-005-R15** Exceptions for external forwarding require approval from the Security Analyst.
16. **POL-005-R16** Suspected phishing mails are reported with the report button; see POL-010.
17. **POL-005-R17** Deleted items are recoverable for 30 days.
18. **POL-005-R18** Mobile devices must use the managed mail application.
19. **POL-005-R19** Sign-in problems only on the mobile device are handled through device registration.
20. **POL-005-R20** Mail delivery delays of more than 30 minutes are escalated to an engineer.
21. **POL-005-R21** Distribution lists are managed through a ticket by the list owner.
22. **POL-005-R22** Mailbox access for departed employees is granted to the manager only through the offboarding process (POL-020).
23. **POL-005-R23** The response must cite this policy by document ID and effective date.
