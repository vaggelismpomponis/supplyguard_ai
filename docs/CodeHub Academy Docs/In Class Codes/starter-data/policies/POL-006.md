# Shared Mailbox Setup

A shared mailbox is requested by the team manager. IT creates it within 2 working days. Members are added through a ticket; the employee opens Outlook and the mailbox appears automatically within 60 minutes.

This is guidance only; no approval is needed to explain the process. The creation itself is a ticket.

## Rules

1. **POL-006-R01** A shared mailbox is requested by the team manager, not by individual members.
2. **POL-006-R02** The request is made through a ticket.
3. **POL-006-R03** The ticket must contain the mailbox name and the list of members.
4. **POL-006-R04** Mailbox names follow the pattern team-purpose@nimbus-analytics.example.
5. **POL-006-R05** IT creates the shared mailbox within 2 working days.
6. **POL-006-R06** Members are added through a ticket approved by the mailbox owner.
7. **POL-006-R07** Each shared mailbox has exactly one owner and at least one deputy.
8. **POL-006-R08** Members see the mailbox in Outlook automatically within 60 minutes.
9. **POL-006-R09** No password exists for a shared mailbox; direct sign-in is disabled.
10. **POL-006-R10** Members with Send As permission must be listed explicitly.
11. **POL-006-R11** Send on Behalf is the default permission for new members.
12. **POL-006-R12** The default quota is 50 GB, the same as a personal mailbox.
13. **POL-006-R13** Retention follows the standard email policy (POL-005).
14. **POL-006-R14** Shared mailboxes are reviewed every 6 months by the owner.
15. **POL-006-R15** Unused shared mailboxes (no activity for 180 days) are archived.
16. **POL-006-R16** Removing a member is done through a ticket by the owner.
17. **POL-006-R17** When a member leaves the company, membership is removed through offboarding (POL-020).
18. **POL-006-R18** Shared mailboxes may not be used for storing confidential HR or legal documents.
19. **POL-006-R19** Auto-replies for a shared mailbox are configured by the owner.
20. **POL-006-R20** The assistant may explain this process without approval; creating the mailbox requires a ticket and approval.
21. **POL-006-R21** If the mailbox does not appear after 60 minutes, the employee restarts Outlook and then opens a ticket.
22. **POL-006-R22** Employees whose team is unknown in the system can still request through their manager's name.
23. **POL-006-R23** The response must cite this policy by document ID and effective date.
