# Suspected Phishing and Compromised Credentials

If an employee clicked a link or entered credentials on a suspicious page, escalate to an engineer at once. Do not reset the password automatically; the Security Analyst decides on containment.

Report the original email using the phishing report button.

## Rules

1. **POL-010-R01** If an employee clicked a suspicious link, the case is escalated to an engineer at once.
2. **POL-010-R02** If an employee entered credentials on a suspicious page, the case is escalated at once.
3. **POL-010-R03** The Security Analyst decides on containment.
4. **POL-010-R04** The assistant must not reset the password automatically in this case.
5. **POL-010-R05** The case is priority P1 with a first response within 30 minutes.
6. **POL-010-R06** Escalation creates a ticket and requires explicit approval.
7. **POL-010-R07** The employee is asked for the time of the click and the device used.
8. **POL-010-R08** The employee is asked to disconnect the device from the network if malware is suspected.
9. **POL-010-R09** The employee must not delete the original email.
10. **POL-010-R10** The original email is forwarded using the phishing report button.
11. **POL-010-R11** The engineer revokes active sessions after consulting the Security Analyst.
12. **POL-010-R12** The engineer may reset credentials only after the Security Analyst confirms.
13. **POL-010-R13** MFA registrations are reviewed for unknown devices.
14. **POL-010-R14** Mailbox rules are checked for unauthorised forwarding.
15. **POL-010-R15** Other recipients of the same email are identified and warned.
16. **POL-010-R16** The incident is recorded even if no credentials were entered.
17. **POL-010-R17** Suspicious emails without a click are handled as a normal report (priority P3).
18. **POL-010-R18** Phishing simulations are run quarterly and results are shared with managers.
19. **POL-010-R19** Repeated phishing failures lead to mandatory training.
20. **POL-010-R20** Phishing involving finance staff is also reported to the Finance Manager.
21. **POL-010-R21** Client data exposure is reported to Legal Counsel.
22. **POL-010-R22** Lessons learned are shared with all employees within 10 working days.
23. **POL-010-R23** The response must cite this policy by document ID and effective date.
