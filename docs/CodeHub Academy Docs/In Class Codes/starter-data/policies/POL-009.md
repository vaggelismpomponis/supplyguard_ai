# Lost or Stolen Device

A lost or stolen laptop or phone is a security incident. The assistant must NOT try to resolve it alone: escalate to an IT support engineer and the Security Analyst immediately.

The device is remotely locked and wiped by an engineer. The employee must file a police report if the device was stolen.

## Rules

1. **POL-009-R01** A lost or stolen laptop or phone is a security incident.
2. **POL-009-R02** The assistant must not try to resolve it alone.
3. **POL-009-R03** The case is escalated to an IT support engineer immediately.
4. **POL-009-R04** The Security Analyst is notified at the same time.
5. **POL-009-R05** The case is priority P1 and the first response is within 30 minutes.
6. **POL-009-R06** Escalation creates a ticket and requires explicit approval.
7. **POL-009-R07** Credential resets are not proposed automatically in this case.
8. **POL-009-R08** The engineer decides whether to reset credentials, after identity verification.
9. **POL-009-R09** The device is remotely locked as soon as possible.
10. **POL-009-R10** The device is remotely wiped when it has not been recovered after 24 hours.
11. **POL-009-R11** Active sessions of the employee are revoked by the engineer.
12. **POL-009-R12** The employee must report the loss within 2 hours of discovering it.
13. **POL-009-R13** Theft requires a police report; the report number is added to the ticket.
14. **POL-009-R14** Loss of a device containing client data is reported to Legal Counsel.
15. **POL-009-R15** Legal Counsel decides on client or regulator notification.
16. **POL-009-R16** Employees must not try to buy or install replacements on their own.
17. **POL-009-R17** A replacement device is issued through the standard request process.
18. **POL-009-R18** The last known location and time of the loss are recorded.
19. **POL-009-R19** Full-disk encryption is mandatory, which limits the data risk.
20. **POL-009-R20** Lost accessories without data (chargers, mice) are a normal request.
21. **POL-009-R21** Repeated losses by the same employee are reported to the manager.
22. **POL-009-R22** The incident is reviewed by the Security Analyst within 5 working days.
23. **POL-009-R23** The response must cite this policy by document ID and effective date.
