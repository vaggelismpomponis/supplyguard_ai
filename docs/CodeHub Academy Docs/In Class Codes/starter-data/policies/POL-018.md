# Backup and File Restore

Backups run nightly and are retained for 30 days. File restores are requested through a ticket and completed within 1 working day.

Restores of finance data need Finance Manager approval.

## Rules

1. **POL-018-R01** Backups run nightly at 02:00.
2. **POL-018-R02** Daily backups are retained for 30 days.
3. **POL-018-R03** Monthly backups are retained for 12 months.
4. **POL-018-R04** Backups are encrypted at rest.
5. **POL-018-R05** Backups are copied to a second location weekly.
6. **POL-018-R06** File restores are requested through a ticket.
7. **POL-018-R07** The ticket must contain the file path and the date of the desired version.
8. **POL-018-R08** File restores are completed within 1 working day.
9. **POL-018-R09** Restores are priority P4 unless business-critical data is lost.
10. **POL-018-R10** Restores of finance data require Finance Manager approval.
11. **POL-018-R11** Restores of HR data require HR Manager approval.
12. **POL-018-R12** Restores of legal data require Legal Counsel approval.
13. **POL-018-R13** Restoring to the original location overwrites the current file; this is confirmed with the requester.
14. **POL-018-R14** Restore to an alternative location is the default.
15. **POL-018-R15** Employees are encouraged to use version history first.
16. **POL-018-R16** Deleted files in the Document Library are recoverable for 30 days.
17. **POL-018-R17** Mailbox restores are handled by the Email Service procedure.
18. **POL-018-R18** Full system restores are performed by the Systems Administrator only.
19. **POL-018-R19** Restore tests are performed quarterly.
20. **POL-018-R20** Backup failures are reported to the IT Support Lead the next morning.
21. **POL-018-R21** The Backup Service depends on the File Server.
22. **POL-018-R22** Backups are not a substitute for the archive.
23. **POL-018-R23** The response must cite this policy by document ID and effective date.
