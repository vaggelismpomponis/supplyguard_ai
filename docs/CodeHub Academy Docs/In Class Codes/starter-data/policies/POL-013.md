# Remote Work and Home Connectivity

Employees working remotely must use the corporate VPN to reach internal systems. Home network faults are the employee's responsibility; IT supports the VPN client only.

If the VPN fails, follow POL-001.

## Rules

1. **POL-013-R01** Employees working remotely must use the corporate VPN to reach internal systems.
2. **POL-013-R02** Remote work from abroad for more than 14 days needs HR and manager approval.
3. **POL-013-R03** Work from countries outside the approved list is not allowed.
4. **POL-013-R04** IT supports the VPN client only, not the employee's home network.
5. **POL-013-R05** Home router faults are the employee's responsibility.
6. **POL-013-R06** Employees should test their connection on a second device before contacting IT.
7. **POL-013-R07** If the VPN fails, follow POL-001.
8. **POL-013-R08** Check open outages before any account action.
9. **POL-013-R09** Company devices must be locked when unattended.
10. **POL-013-R10** Company devices must not be used by family members.
11. **POL-013-R11** Public Wi-Fi is allowed only with the VPN active.
12. **POL-013-R12** Sensitive calls and screen sharing should not take place in public places.
13. **POL-013-R13** Printing at home is not supported.
14. **POL-013-R14** Documents must be stored on the file server or the Document Library, not on local disks.
15. **POL-013-R15** Remote work equipment (monitor, headset) is requested through a normal ticket.
16. **POL-013-R16** Ergonomic equipment requests are handled by the Facilities Coordinator.
17. **POL-013-R17** Remote support sessions require the employee's consent.
18. **POL-013-R18** Remote support sessions are recorded in the ticket.
19. **POL-013-R19** Employees must install updates within 7 days of release.
20. **POL-013-R20** Security incidents while remote are reported immediately; see POL-010.
21. **POL-013-R21** Lost devices while remote follow POL-009.
22. **POL-013-R22** Remote work days are agreed with the manager.
23. **POL-013-R23** The response must cite this policy by document ID and effective date.
