# Wi-Fi and Office Network

Corporate Wi-Fi uses certificate-based authentication on managed devices. Guests use the guest network with a daily voucher from reception.

Wi-Fi problems on a managed device require the device name and the office; open a ticket for the network team.

## Rules

1. **POL-012-R01** Corporate Wi-Fi uses certificate-based authentication on managed devices.
2. **POL-012-R02** Personal devices must not join the corporate Wi-Fi.
3. **POL-012-R03** Guests use the guest network.
4. **POL-012-R04** Guest vouchers are issued daily by reception.
5. **POL-012-R05** Guest vouchers expire at 23:59 on the day of issue.
6. **POL-012-R06** The guest network has no access to internal systems.
7. **POL-012-R07** Wi-Fi problems require the device name and the office.
8. **POL-012-R08** If missing, ask for the device name and the office before acting.
9. **POL-012-R09** Check open outages on the Office Network & Wi-Fi before opening a ticket.
10. **POL-012-R10** Link the request to the outage if it explains the symptom.
11. **POL-012-R11** Certificates are renewed automatically every 12 months.
12. **POL-012-R12** An expired certificate is fixed by re-enrolling the device through a ticket.
13. **POL-012-R13** Wi-Fi tickets are priority P3.
14. **POL-012-R14** Wired network ports are active only in meeting rooms and the IT room.
15. **POL-012-R15** Network equipment is managed by the Systems Administrator only.
16. **POL-012-R16** Employees must not connect their own routers or switches.
17. **POL-012-R17** Rogue access points are reported to the Security Analyst.
18. **POL-012-R18** Wi-Fi coverage problems are logged with room and time.
19. **POL-012-R19** Bandwidth-heavy downloads should be done outside core hours where possible.
20. **POL-012-R20** Network maintenance windows are announced 3 working days in advance.
21. **POL-012-R21** Wi-Fi does not depend on the Identity Provider for managed devices.
22. **POL-012-R22** Wi-Fi logs are retained for 90 days.
23. **POL-012-R23** The response must cite this policy by document ID and effective date.
