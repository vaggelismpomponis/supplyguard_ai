# Printer and Print Queue Troubleshooting

Check the service status for the Print Service first. If an outage is open for the employee's office, link the request to it.

Otherwise clear the print queue, restart the Print Manager and, if the problem persists, open a normal ticket with the printer name and location.

## Rules

1. **POL-011-R01** Check the status of the Print Service before any other step.
2. **POL-011-R02** If an open outage covers the employee's office, link the request to the outage.
3. **POL-011-R03** An outage in Athens does not explain a printer problem in London.
4. **POL-011-R04** Do not open a separate ticket for a symptom that an open outage explains.
5. **POL-011-R05** Ask for the printer name and the office if missing.
6. **POL-011-R06** Clear the print queue as the first self-service step.
7. **POL-011-R07** Restart the Print Manager application as the second step.
8. **POL-011-R08** If the problem persists, open a normal ticket with printer name and location.
9. **POL-011-R09** Printer tickets are priority P3.
10. **POL-011-R10** Print jobs larger than 200 pages require the large-job queue.
11. **POL-011-R11** Colour printing is limited to the Operations and Sales teams by default.
12. **POL-011-R12** Confidential printing uses badge release at the printer.
13. **POL-011-R13** Jobs not released are deleted after 24 hours.
14. **POL-011-R14** Toner replacement is requested through the Facilities Coordinator.
15. **POL-011-R15** Paper jams are cleared by the employee following the printer guide.
16. **POL-011-R16** Repeated jams on the same device are reported through a ticket.
17. **POL-011-R17** New printers are added by IT only.
18. **POL-011-R18** Personal printers must not be connected to company devices.
19. **POL-011-R19** Home printing is not supported by IT.
20. **POL-011-R20** Printing from mobile devices uses the secure print email address.
21. **POL-011-R21** Print outage updates are published on the service status page.
22. **POL-011-R22** After the outage is resolved, stuck jobs are cleared by the Systems Administrator.
23. **POL-011-R23** The response must cite this policy by document ID and effective date.
