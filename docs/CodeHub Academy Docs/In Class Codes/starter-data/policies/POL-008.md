# Software Installation Requests

Employees may not install software themselves. Requests go through a ticket, include a business justification, and are reviewed within 3 working days.

Approved software is installed remotely. Software with a licence cost requires budget approval from the team manager.

## Rules

1. **POL-008-R01** Employees may not install software themselves.
2. **POL-008-R02** Installation requests go through a ticket.
3. **POL-008-R03** The ticket must contain a business justification.
4. **POL-008-R04** The ticket must contain the device name and the employee's team.
5. **POL-008-R05** Requests are reviewed within 3 working days.
6. **POL-008-R06** A software request is a normal request with priority P4.
7. **POL-008-R07** Urgency stated by the employee may raise priority by at most one level.
8. **POL-008-R08** Approved software is installed remotely by IT Support.
9. **POL-008-R09** Software on the approved catalogue is installed without further review.
10. **POL-008-R10** Software not on the catalogue requires a security review by the Security Analyst.
11. **POL-008-R11** Software with a licence cost requires budget approval from the team manager.
12. **POL-008-R12** Free software with commercial restrictions is checked by Legal Counsel.
13. **POL-008-R13** Open-source tools are allowed after a licence check.
14. **POL-008-R14** Browser extensions are managed centrally and cannot be installed by employees.
15. **POL-008-R15** Administrator rights are not granted to employees.
16. **POL-008-R16** Short-term administrator rights require IT Support Lead approval and expire after 4 hours.
17. **POL-008-R17** Software for client workshops must be requested at least 5 working days in advance.
18. **POL-008-R18** Installed software is recorded in the asset inventory.
19. **POL-008-R19** Software that is no longer used for 180 days is removed.
20. **POL-008-R20** Personal software must not be installed on company devices.
21. **POL-008-R21** Pirated or unlicensed software leads to removal and escalation to the manager.
22. **POL-008-R22** Creating the software ticket requires explicit approval of the support engineer.
23. **POL-008-R23** The response must cite this policy by document ID and effective date.
