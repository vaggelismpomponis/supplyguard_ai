# MFA Enrolment and Recovery

New employees enrol an authenticator app during onboarding. Lost or replaced phones require a verified MFA reset ticket.

MFA resets are account changes and need explicit approval. If MFA prompts are not arriving and an Identity Provider outage is open, link to the outage.

## Rules

1. **POL-003-R01** New employees enrol an authenticator app during onboarding on their first day.
2. **POL-003-R02** Hardware security keys are available on request for administrators.
3. **POL-003-R03** SMS codes are allowed only as a temporary fallback for 7 days.
4. **POL-003-R04** Each employee may have a maximum of 3 registered MFA devices.
5. **POL-003-R05** A replaced or lost phone requires a verified MFA reset ticket.
6. **POL-003-R06** MFA resets are account changes and require explicit approval before execution.
7. **POL-003-R07** The employee identity must be verified by manager confirmation before an MFA reset.
8. **POL-003-R08** Verification by email address alone is not sufficient.
9. **POL-003-R09** Backup codes are generated at enrolment and stored by the employee, never by IT.
10. **POL-003-R10** Backup codes are valid once and expire after 90 days.
11. **POL-003-R11** If MFA prompts are not arriving, check open Identity Provider outages first.
12. **POL-003-R12** If an Identity Provider outage explains missing prompts, link the request to the outage.
13. **POL-003-R13** Do not reset MFA while an explaining outage is open.
14. **POL-003-R14** Time drift on the phone is a common cause; ask the employee to enable automatic time.
15. **POL-003-R15** An MFA reset invalidates all existing sessions of the employee.
16. **POL-003-R16** After a reset the employee must re-enrol within 24 hours.
17. **POL-003-R17** Five failed MFA challenges lock the account; see POL-004.
18. **POL-003-R18** Administrators must use hardware keys; authenticator apps are not accepted for them.
19. **POL-003-R19** MFA cannot be disabled for any account, even temporarily.
20. **POL-003-R20** Exceptions for shared devices require approval by the IT Support Lead.
21. **POL-003-R21** Travel abroad does not change the MFA method.
22. **POL-003-R22** MFA events are retained in logs for 12 months.
23. **POL-003-R23** The response must cite this policy by document ID and effective date.
