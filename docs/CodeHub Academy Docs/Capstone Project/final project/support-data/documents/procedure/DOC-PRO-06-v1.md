# Inventory transfers and usable stock

Usable stock = on hand - reserved - quarantined. Quarantined lots cannot be transferred or consumed. Reserved stock may be reallocated only through the customer-priority procedure (PRO-07). Inter-factory transfer: 2 working days, EUR 0.12 per unit.
