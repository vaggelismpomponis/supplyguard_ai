# Source precedence and conflicting information

Order of authority: (1) signed contract, latest version in force; (2) supplier qualification record; (3) formal supplier notice; (4) supplier e-mail; (5) informal chat. A later effective_date supersedes an earlier version of the same document type. When sources conflict, report the conflict, state which source was used and why, and flag uncertainty. Quantities from e-mail never override contractual capacity without written confirmation.
